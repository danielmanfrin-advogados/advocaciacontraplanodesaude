Existem sete páginas: início, três serviços (negativa de cobertura; tratamentos, terapias e medicamentos; reajuste ou cancelamento), sobre, perguntas frequentes e política de privacidade. ## Configuração de contato

Altere WhatsApp e telefone somente em `config.js`, no formato internacional de dígitos, por exemplo `55 + DDD + número`. Os links HTML começam com o número provisório `5516900000000`; `tracker.js` substitui os links pelo número de `config.js` quando a página carrega. As mensagens padrão também estão em `config.js` e os textos por assunto são genéricos, sem pedir documentos ou dados de saúde.

## Apps Script e planilha

`apps-script/Code.gs` é a cópia exata do script fornecido no prompt. As instruções abaixo são para o responsável executar manualmente na planilha, não foram executadas nesta entrega. Se for usar o script: abra a planilha correta, selecione **Extensões > Apps Script**, revise o código, cole o `Code.gs` e execute `setup()` uma vez para criar os cabeçalhos e a aba de resumo. Para atualizar uma implantação existente, use **Implantar > Gerenciar implantações > Editar > Nova versão**; confirme a URL atual antes de salvar.

**Cautela de segurança e privacidade:** conforme solicitado, não há banner de consentimento e o tracker registra automaticamente cliques em WhatsApp/telefone. Envia tipo/posição do botão, caminho da página, origem/referrer, meio/campanha/termo UTM, presença de gclid, tipo de dispositivo, resolução, idioma, sessão aleatória e mensagem genérica pré-preenchida; não envia nome, e-mail, CPF ou documentos médicos. O `doGet` aceita parâmetros públicos sem validar origem ou token, então qualquer pessoa com a URL pode enviar cliques falsos. Antes da publicação, confirme a base legal, retenção, acesso à planilha e proteção server-side; um segredo no JavaScript público não protege a chamada. Nenhum evento de teste foi enviado.

Para montar uma tabela dinâmica no Sheets, selecione os dados da aba `Cliques` e use **Inserir > Tabela dinâmica**; coloque `Site` em Linhas e `Botão` em Colunas/Valores, usando contagem. Confira os nomes das colunas e permissões antes de compartilhar relatórios.

## Build e deploy na Vercel

Não há React, Vite ou dependências externas. `package.json` contém somente o script de build e `build.js` usa APIs nativas do Node para copiar os arquivos do site a `dist/`, excluindo documentação interna, `app.config.ts` e `apps-script/Code.gs` da saída pública.

```sh
npm install --package-lock=false
npm run build
```

Na Vercel, selecione Framework Preset **Other**, Build Command `npm run build` e Output Directory `dist`. `vercel.json` já define `cleanUrls: true` e `trailingSlash: true`. Não crie `package-lock.json`.
